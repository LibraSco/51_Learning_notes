# 使用NE555方波发生器测量频率

NE555方波发生器：

NE555的核心功能是将被测信号转化为规整的方波，以便于单片机能够更加准确地测量频率

NE555的配置模式主要为单稳态模式：若被测信号是随机脉冲，NE555可输出固定频率的方波

**频率测量原理：在固定时间内（通常是用1秒），统计方波的上升沿次数**

**编程思路：**

**1.配置定时器（Timer0）为 定时模式，定时精确的1秒**

**2.配置计数器（Timer1）为 计数模式，接收 NE555 输出的方波信号**

**3.当 1秒 时间到，读取计数器的值，即为信号的频率（单位 Hz）**

---

1.计数初始化函数如下：（注意，该初始化函数需要放在main函数中调用一次，目的是将计数器和定时器清零）

```cpp
void Counter0_Init(void){
 TMOD |=0x05; //计数器0/定时器0配置计数模式
 TL0=0x00; //TL0初值为0
 TH0=0x00; //TH0初值为0
 TR0=1; //启动计数器
}
```

2.频率读取函数：

由于频率测量函数对时间的精确度要求很高，所以可以将函数放在中断函数当中执行。当然也可以单独写一个频率读取函数，然后再将函数放在中断中。

```cpp
unsigned char cnt_ne555;
unsigned int freq;
void Timer2_ISR()  interrupt 12{
 cnt_ne555++;
 if(cnt_ne555>=1000)
 {
  cnt_ne555=0;
  freq=(TH0<<8)|TL0;
  TL0=0;
  TH0=0;
 }
}
```

解释：

1.TH0储存了频率值的高8位数据，TL0储存的是低8位数据，所以在计算频率的时候需要先将TH0左移8位，再使用 | 运算符

2.在得到频率值之后，需要将之前的计数（TH0，TL0）清零，才能进行下一次的测量

3.注意，这里频率变量应该定义为unsigned int类型，因为频率的取值范围超出了unsigned char(0~255)的最大范围。如果使用unsigned char类型也会出现频率读取错误的情况
