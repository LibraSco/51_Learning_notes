# 独立按键（三行按键法）

上一篇博客介绍了状态机法，但是程序代码量巨大，不便于记忆，接下来给大家介绍三行按键法，不仅方便记忆，还可以在考场上领先别人一大步。

以下是三行按键法的读取函数，这个函数理解起来比较复杂，大家也没有必要硬要理解，能把代码背下来就好了

```cpp
unsigned char Trg;
unsigned char Cont;
void vBTN_Read_ThreeLine(void){
	unsigned char ReadData=P3^0xff;
	Trg= ReadData &(ReadData^Cont);
	Cont=ReadData;
}
```
